# 衛教工作台需求訪談與 Pilot 套件（#20，尚未執行）

目前沒有受訪者、訪談紀錄或 Pilot 數據。此文件只準備執行方法與空白紀錄，不能當成產品假設已驗證。
第一輪目標為 3–5 位衛教師、護理師或醫療文件維護者。由使用者安排聯繫；不代寄邀請、不假造受訪者。

## 訪談方式（每位約 30 分鐘）

先說明這是合成／經授權非個人資料的軟體原型，請受訪者不要提供病歷、姓名或可識別的患者案例。
以 P01–P05 等代號記錄角色與工作環境；錄音或其他個人資料收集需先取得當事人同意。

1. 請回想最近一次查找衛教文件：從哪裡找、如何判斷是否最新版、通常要花多久？
2. 不同院區／科別的文件有何差異？誰負責內容與有效日期？什麼情況最容易用錯？
3. 草稿目前怎麼撰寫、修改、送審與發布？哪些步驟最耗時？退回最常見的理由是什麼？
4. 什麼問題應直接轉交專業人員，不適合自動回答？請只描述問題類型，不使用真實患者資料。
5. 對引用原文、版本、頁碼、人工核准與撤回，哪些是必要條件？公開資料是否另需使用授權？
6. 用現有工具完成同一工作，哪些功能已足夠？這個原型真正減少了哪個步驟？
7. 是否有試用／導入意願？決策者、預算流程、部署位置、身份管理與維運限制為何？
8. 若只能先解決一件事，會選什麼？原型仍缺什麼，才願意下一次使用？

避免誘導「你覺得這很有用嗎」。記錄原話或具體行為，清楚區分觀察、受訪者說法及研究者推測。

## Pilot 任務與量測

使用相同的合成內容，交錯安排先用既有流程或先用工具，避免所有人都固定同一順序。
計時包含查找、核對來源、修改與審核，不只量 LLM 回應速度。每題記錄是否完成與需人工協助。

| 任務 | 觀察與量測 |
|---|---|
| 找到指定院區的現行核准文件，說出來源與版本 | 秒數、來源／版本是否正確、誤用舊版次數 |
| 點引用並核對 PDF 原文頁碼／文字 | 秒數、定位是否成功、引用是否支持陳述（專業審查） |
| 遇到沒有核准證據的問題 | 是否清楚拒答、有無虛構院所流程、受訪者是否知道下一步 |
| 用核准來源產生檢查前衛教稿，再修改／送審 | 完成時間、修改字數／段落、退回理由、需人工核對的部分 |
| 審核後發布，再撤回並核對一般讀者入口 | 權限是否正確、撤回是否生效、事件是否可追溯 |

建議錯誤分類：找不到文件、錯版本、錯院區／科別、錯頁碼、引用不支持、無證據仍回答、
越過個人化診療邊界、權限錯誤、UI 操作困難、其他。每個分類要附可重現的非個人操作描述。

## 報告格式與完成條件

填寫 `pilot-report.template.json`。對每位參與者記錄匿名代號／角色、任務順序、原流程與工具耗時、
來源核對結果、修訂量與錯誤類型。只對實際完成的配對任務比較時間；列出人數與缺失資料，
不以 3–5 人推論整體市場或臨床安全。沒有完成的任務也要記錄，不能刪除不利結果。

最後分開列出：

- 已由觀察支持的假設及反例、仍未驗證的假設。
- 實際效率／來源正確性／修訂結果，包含失敗案例及限制。
- 依嚴重度與頻率排序的需求；導入意願與部署限制的匿名原話。
- 是否進入下一輪，以及需要改善／補測的項目。

#20 只有在完成真實訪談與 Pilot、產生匿名紀錄和實測報告後才能關閉。若無合作對象，明列限制。
本輪不使用真實患者資料；後續若要使用，須另完成相應授權與合規評估。
