# 工作台查詢紀錄

在 `/knowledge?view=history` 或左側「查詢紀錄」開啟目前帳號最近 50 筆對話，可依標題搜尋、閱讀問題與回答、開啟引用原文、查看追溯及回報答案問題。「新查詢」會開啟空白表單。

每則新回答在同一筆資料庫交易保存對應的追溯 ID，並驗證對話及擁有者一致；不一致時整筆儲存回復。歷史顯示原查詢範圍與時間，不套用現在的範圍選單。舊訊息沒有逐則追溯 ID 時，只提供該對話的追溯清單，不推測答案與追溯的配對。

訊息欄位存於既有 JSON metadata，無須新增資料庫 migration。讀取及開啟來源仍重新核對權限與文件版本，撤回來源的歷史回答繼續遮蔽。示範自動連線仍啟用；使用同一示範帳號的瀏覽器會看到同一份該帳號紀錄。
